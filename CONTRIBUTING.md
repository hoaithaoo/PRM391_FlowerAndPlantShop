# Contributing

Trước khi bắt đầu, đọc:

1. [Tổng quan hệ thống](docs/system-overview.md)
2. [Team conventions](docs/team-conventions.md)
3. [Thiết lập Supabase và Render](docs/supabase-render-setup.md)

Luồng đóng góp mặc định:

```text
ticket -> branch -> implementation -> local checks -> pull request -> review -> CI -> squash merge
```

Không đưa secret vào issue, commit, screenshot, log hoặc pull request.
