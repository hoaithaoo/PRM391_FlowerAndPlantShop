# Store artwork

Original platform icons, stored locally to avoid a third-party request on every page load:

- App Store: https://developer.apple.com/assets/elements/icons/app-store/app-store-128x128_2x.png
- Google Play: https://www.gstatic.com/images/branding/product/2x/play_prism_64dp.png

The platform names and icons identify the intended app stores. Download links remain disabled with “Sắp ra mắt” until the corresponding public store URLs are configured.
